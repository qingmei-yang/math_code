# Problem A · 快递公司送货策略（数学建模）

## 题目
公司总部位于坐标原点，送货路线为**平行于坐标轴的折线**（→ 用曼哈顿距离）。
30 个送货点，快件总重 **184.5 kg**。
- 9:00 开始派送，17:00 前完成；每个业务员每天工作 ≤ 6 小时；
- 每个送货点停留 10 分钟；途中速度 25 km/h；每次出发最多携带 25 kg。

**三问：**
1. 合理送货策略（需要多少业务员、每人运行线路、总运行公里数）
2. 载货 20 km/h、酬金 3 元/(km·kg)；空载 30 km/h、酬金 2 元/km → **费用最省**策略
3. 工作时间延长到 8 小时，策略有何变化

## 模型要点
- **距离**：曼哈顿距离 `|Δx|+|Δy|`（折线路线，非欧氏）
- **两阶段建模**：一个业务员一天可跑**多趟**（每趟从总部出发、载重≤25kg、回到总部）
  - **分趟**：每趟载重 ≤ 25kg、单趟 ≤ 6h。算法 = 最远点优先 + MOVE/SWAP 局部搜索
    （Q1/Q3 目标 = 少趟 + 短路程；Q2 目标 = 费用最省）
  - **打包**：把趟按时间 FFD 装入业务员（每人 ≤ 6h，Q3 为 8h）
- **Q2 费用**：沿访问顺序卸货、载重递减；
  载货段费用 = Σ `3 × 段距离 × 该段载重`；空载回程 = `2 × 回程距离`

## 运行
```bash
python data_points.py    # 数据自检（输出 184.5 kg）
python problem1.py       # 第一问
python problem2.py       # 第二问
python problem3.py       # 第三问
```

## 结果（基于题目数据）
| 问题 | 趟数 | 业务员 | 关键指标 |
|---|---|---|---|
| Q1（6h 策略） | 8 | **5 人** | 总路程 478.0 km |
| Q2（费用最省） | 9 | 6 人 | 总费用 **13800.7 元** |
| Q3（8h 策略） | 8 | **4 人** | 由 6h 的 5 人降至 4 人 |

**Q3 结论**：工作时间延长到 8 小时后，每名业务员可承担更多趟，业务员数 **5 → 4**（减少 1 人），总路程不变。
